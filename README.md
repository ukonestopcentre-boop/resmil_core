# RESMIL Core

Minimal custom Frappe app for RESMIL Desk styling.

Loads `resmil_desk.css` into the Frappe Desk using `app_include_css`.
The CSS changes Number Card title labels to white within Frappe workspaces.

This app changes presentation only. It does not alter Number Card calculations,
financial records, permissions, workflows, or standard ERPNext/Lending code.

Install through Frappe Cloud using the app's Git repository URL, then hard-refresh
the Desk (Ctrl+Shift+R).
